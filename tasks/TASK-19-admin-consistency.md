# TASK-19 — АРМ администратора: ошибки не затирают друг друга, публикация необратима,
# специальности синхронны

Три находки приёмки прогона `g_20260806-195014` (**P2**):

- **Параллельные загрузки затирают ошибки друг друга.** Оба запроса делят один
  `loadError`, и успех каждого безусловно его очищает ([admin-page.tsx:49],
  [admin-page.tsx:66]). Успех справочника после ошибки шаблонов даёт вечную «Загрузку»,
  обратный порядок — молча пустой справочник.
- **Флаг `published` мёртв в интерфейсе:** кнопка блокируется только на время запроса
  ([week-templates.tsx:97]), поэтому уже опубликованную — необратимую по требованиям —
  неделю экран снова предлагает публиковать и получает 409.
- **Специальность врача расходится между справочниками:** `PATCH` обновляет
  `DoctorCard.specialties`, но в общей записи врача синхронизирует только кабинет
  ([directories.js:50]). `/doctors`, сетка оператора и карточка администратора продолжают
  показывать старое значение.
