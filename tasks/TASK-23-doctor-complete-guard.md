# TASK-23 — врач: завершить приём можно только из допустимого статуса

Находка приёмки прогона `g_20260808-173152`, **P1**: форма блокирует завершение только для
`completed` ([doctor-page.tsx:116]), то есть разрешает завершать `scheduled` и `no_show`.
Сервер после TASK-15 разрешает переход в `completed` лишь из `arrived` или `in_progress`.
Выбранная по умолчанию `scheduled`-запись после заполненного протокола отклоняется с 409, а
введённые врачом данные остаются только в памяти вкладки — то есть теряются.

## Файлы

- `src/pages/doctor/doctor-page.tsx`
- `src/pages/doctor/visit-form.tsx`
- `src/pages/doctor/complete-guard.test.tsx`

## Вход

TASK-21

## Готовность

1. «Завершить приём» доступно только из статусов, из которых сервер разрешает переход;
   в остальных случаях кнопка недоступна и рядом сказано, чего не хватает (например,
   «сначала отметьте приход»).
2. Отказ сервера на переход показывается врачу текстом, а введённый протокол не теряется:
   форма сохраняет введённое и позволяет повторить действие.
3. Тест доказывает: для `scheduled`-записи завершение недоступно, после перевода в
   `arrived` — доступно и уходит на сервер; при 409 введённые данные остаются в форме.
