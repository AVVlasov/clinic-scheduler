# TASK-44 — петля администратора замыкается

Публикация недели — булев флаг видимости поверх вечной константы. Шаблоны приёма лежат
модульной константой вне состояния, редактируемого состояния у них нет, маршрута правки
не существует. Ячейка шаблона в интерфейсе — два текста в контейнере, тогда как в макете
на её месте кнопка.

Из этого следует всё остальное:

- недели неотличимы: нормализованные сетки любых двух недель совпадают, потому что
  шаблон читается по индексу дня, а измерения «неделя» в модели нет;
- главная кнопка экрана мертва с первой секунды: сидинг публикует текущую неделю, и
  повторная публикация отвечает 409, а обратной операции нет — демонстрацию нельзя
  показать дважды;
- подпись о результате публикации неверна: `slotsCreated` считает времена, схлопнутые по
  врачам, а не пары «врач × время», и число в сообщении меньше настоящего примерно втрое.

## Готовность

1. Шаблоны недели — часть состояния сервера, а не константа модуля; у каждой недели своё
   содержимое. Тест: правка интервала в одной неделе не меняет соседнюю.
2. Есть маршрут правки интервала и интерактивная ячейка в интерфейсе: тип интервала и
   границы меняются, изменение сохраняется и переживает перезагрузку экрана.
3. Публикация замыкает петлю: после правки интервала и публикации `GET /schedule` за день
   этой недели отдаёт **другое** число слотов, и оператор видит эту дату в своей сетке.
4. Публикацию можно снять: экран не оказывается в состоянии, из которого нет выхода.
5. `slotsCreated` равен числу пар «врач × время» и совпадает с суммой длин `slots.doctors`
   по дням недели. Тест сверяет эти два числа между собой, а не с константой.
6. Сценарий `admin-publish-week` заведён, зелёный и переведён в `required`.
