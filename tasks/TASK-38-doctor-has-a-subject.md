# TASK-38 — у АРМ врача появляется субъект

«АРМ врача» — это сейчас АРМ всех врачей сразу. Понятия «кто я» нет ни в адресе, ни в
состоянии экрана, ни в API: `grep 'doctorId|getDoctors|currentDoctor'` по
`src/pages/doctor/doctor-page.tsx` даёт ноль совпадений на 283 строках. Живьём врач видит
день из записей пяти разных врачей и может завершить чужой приём — сервер инициатора не
сверяет.

Рядом два следствия той же причины: счётчик «N из M завершено» считает по всей клинике и
держит отменённые и неявки в знаменателе, поэтому «8 из 8» недостижимо; плашка
пользователя в шапке — жёсткая строка «Ефимова Т. С.», которой нет в справочнике врачей.

## Вход

- TASK-37 — выборка по врачу добавляется к выборке по дате, а не вместо неё.

## Готовность

1. `GET /appointments?date=d&doctorId=d-002` отдаёт только записи d-002 и не пустой
   список; несуществующий врач — 400.
2. Текущий врач задан в адресе рабочего места и переключается на экране. Плашка
   пользователя в шапке показывает выбранного врача из справочника, а не константу.
3. В дне врача нет чужих записей. Тест: в наборе с записями пяти врачей список показывает
   записи одного.
4. `PATCH /appointments/<id>` с чужим `doctorId` отклоняется с кодом ошибки: запрет
   держится на сервере, а не только тем, что кнопки не видно.
5. «N из M завершено» сходится: знаменатель — записи этого врача за день без отменённых и
   неявок; после завершения последнего приёма счётчик показывает «M из M».
