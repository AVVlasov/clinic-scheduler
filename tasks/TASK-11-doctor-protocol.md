# TASK-11 — АРМ врача: протокол приёма переживает перезагрузку

Находка приёмки (критик «склейка», высокая): жалобы, диагноз, услуги и рекомендации
хранятся только в локальном состоянии формы, а завершение приёма отправляет
`{ status: 'completed' }` — [doctor-page.tsx:103]. Приём закрывается, протокол исчезает.
Стоимость услуг при этом вычисляется из длины названия — [visit-form.tsx:43].

## Готовность

1. Завершение приёма отправляет протокол целиком (жалобы, диагноз, тип приёма, услуги,
   рекомендации) через клиент API, а не один статус.
2. Стоимость услуг берётся из справочника (TASK-10), никаких вычислений из названия или
   длительности в компоненте.
3. Тест доказывает цикл: заполнили форму → завершили приём → перечитали приём из API →
   протокол на месте и совпадает с введённым.
