# TASK-18 — АРМ регистратора: завершённый визит не переоткрывается

Находка приёмки прогона `g_20260806-195014`, **P1**: для визита в статусе `completed`
таблица очереди попадает в общую ветку «Отметить приход» ([queue-table.tsx:241]), доступна
и неявка. После перехода `completed → arrived` врач снова получает возможность завершить
приём и перезаписать протокол — то есть регистратор одним кликом стирает медицинскую
запись.

Серверную часть закрывает TASK-15 (машина состояний), здесь — интерфейс: он не должен
предлагать действие, которое сервер обязан отклонить.

- `src/pages/registrar/visit-card.tsx`
- `src/pages/registrar/registrar-page.test.tsx`

## Вход

TASK-15

## Готовность

1. Для завершённого визита действия «отметить приход» и «отметить неявку» недоступны;
   доступны только чтение и печать талона.
2. Отказ сервера на недопустимый переход показывается человеку понятным текстом, а не
   молча игнорируется.
3. Тест доказывает: в строке завершённого визита кнопок перехода нет, а при попытке
   выполнить такой переход (например, из устаревшего состояния таблицы) на экране
   появляется сообщение об отказе.
