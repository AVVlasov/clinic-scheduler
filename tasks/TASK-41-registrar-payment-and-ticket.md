# TASK-41 — регистратор получает вторую половину смены: оплата и талон

Половина работы регистратора нарисована и не сделана. Обе кнопки — «К оплате» и «Талон» —
`disabled` с подписью «недоступна», без обработчиков, во всех строках очереди и в карточке
визита. В модели нет факта оплаты (есть только способ), на сервере нет маршрута.

Задачу закрыли на уровне «нарисовать кнопку из макета», а слой данных под неё не
спроектировали. Хуже того, мёртвая кнопка **закреплена тестом**: `status-flow.test.tsx`
проверяет её наличие как выполненное требование. Пять кругов приёмки прошли мимо.

Отдельно: «Талон» в строке очереди — это `Box as="button"` с `aria-disabled`, но без
атрибута `disabled` и без остановки всплытия. Клик по нему проваливается в строку и молча
перевыбирает визит; соседние живые кнопки всплытие останавливают.

PRD включает оплату и печать талона в MVP.

## Готовность

1. В модели записи есть факт оплаты: сумма, способ, время. На сервере есть маршрут,
   который его проставляет, и он отклоняет повторную оплату.
2. Регистратор проводит оплату из карточки визита: сумма считается по выполненным услугам
   из справочника, а не по одному полю записи.
3. «Касса смены» равна сумме фактических оплат за день. Тест: до оплаты касса не меняется,
   после — растёт ровно на сумму визита.
4. Талон печатается: экран печати существует, содержит пациента, врача, время, кабинет и
   услугу, и открывается по кнопке. Готовый `print.css` лежит в `ai/05-дизайн/.../_ds`.
5. Ни одной кнопки с подписью «недоступна» в АРМ регистратора не осталось. Тест,
   закреплявший мёртвую кнопку, заменён на тест работающей.
6. Кликабельные элементы внутри строки очереди не перевыбирают визит.
7. Сценарий `registrar-arrive-pay-ticket` заведён, зелёный и переведён в `required`.
