# TASK-02 — тема Chakra по дизайн-системе СМ-Клиники

Все четыре рабочих места собираются из одних и тех же токенов. Пока их нет, каждый экран
подберёт цвет на глаз, и расхождение вылезет уже на приёмке — переделкой всех четырёх.

Источник значений — `ai/05-дизайн/smclinic-Design-System.md`, раздел «Фирменные цвета» и
далее по типографике, форме и плотности. Ничего не выдумывать: если токена в документе нет,
его нет и в теме.

## Файлы

- `src/theme.tsx`
- `src/__data__/tokens.ts`
- `src/__data__/tokens.test.ts`

## Вход

TASK-01

## Готовность

1. `src/__data__/tokens.ts` экспортирует токены дизайн-системы (палитра, шрифты, радиусы,
   шаг сетки 4px) со значениями ровно из документа дизайн-системы.
2. `src/theme.tsx` собирает тему Chakra v3 на этих токенах; приложение продолжает
   рендериться (`npm test` зелёный).
3. Тест доказывает контрастное правило: для текста мельче 18px тема отдаёт `-700`-версии
   (`#0B6B4A`, `#9A4A10`), а не `#0D9B6C` / `#F07A35`.

## Проверки

```
npx --no-install tsc --noEmit
npx --no-install eslint ./src --max-warnings=0
npx --no-install vitest run src/__data__/tokens.test.ts
```

## Что учесть

- Chakra v3 конфигурируется через `createSystem`/`defineConfig`, а не через `extendTheme`
  из v2 — версия в `package.json` авторитетнее любого примера из памяти.
- Шрифты Open Sans и JetBrains Mono лежат в макетах
  (`ai/05-дизайн/Clinic-scheduler UI макеты/_ds/.../assets/fonts`); в теме достаточно имён
  семейств, подключение файлов — не эта задача.
