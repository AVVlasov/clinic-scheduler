# TASK-09 — каркас приложения и навигация между рабочими местами

Четыре экрана существуют по отдельности. Пока их не связал общий каркас, систему нельзя ни
показать, ни пройти сценарием: макеты все четыре начинаются с одной шапки с переключателем
«Оператор · Врач · Регистратор · Администратор».

## Файлы

- `src/app.tsx`
- `src/dashboard.tsx`
- `src/pages/index.ts`
- `src/pages/main/main.tsx`
- `src/pages/main/index.ts`
- `src/pages/app-shell.tsx`
- `src/pages/app-shell.test.tsx`

## Вход

TASK-05, TASK-06, TASK-07, TASK-08

## Готовность

1. Общая оболочка по макету: шапка с логотипом, названием рабочего места, контекстом
   площадки и даты, переключателем рабочих мест и пользователем.
2. Маршруты ведут на все четыре АРМ и живут под базовым адресом навигации
   (`clinic-scheduler.main` из `bro.config.js`); заглушка `MainPage` заменена реальной
   стартовой страницей.
3. Тест доказывает переход: из оболочки открывается каждое из четырёх рабочих мест, и
   активный пункт переключателя соответствует открытому экрану.

## Проверки

```
npx --no-install tsc --noEmit
npx --no-install eslint ./src --max-warnings=0
npx --no-install vitest run src/pages/app-shell.test.tsx
npm test
```

## Что учесть

- Базовый путь берётся из навигации `@brojs/cli`, а не пишется строкой: в проме приложение
  монтируется по другому адресу.
- Переключатель рабочих мест — не меню настроек: он всегда на виду и всегда показывает,
  где ты сейчас.
