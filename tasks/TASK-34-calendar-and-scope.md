# TASK-34 — сервер: воскресенье существует, выборка ограничена днём

Три находки **P1** приёмки прогона `g_20260809-085233`. Первая воспроизводится прямо сейчас:
сегодня 9 августа — воскресенье.

- **Воскресенья нет в модели.** Недельные шаблоны описывают понедельник–субботу, а
  `buildSlots` отвергает `dayIndex=6`. В воскресенье `seedAppointments` отбрасывает все
  записи: расписание пустое, экраны пустые, и это выглядит поломкой, а не выходным.
- **`GET /appointments` возвращает всё накопленное состояние**, хотя клиент и экраны
  трактуют ответ как записи текущего дня. После бронирований на другие даты в очередь
  регистратора и в день врача попадают чужие сутки.

## Готовность

1. Воскресенье — полноценный день модели: у него есть шаблон (пусть выходной), `buildSlots`
   его принимает, демо-данные не теряются. Выходной день отдаёт пустое расписание ЯВНО, а
   не через отбрасывание записей.
2. `GET /appointments` фильтрует по дате (по умолчанию — текущий день) и принимает
   параметр даты; записи других суток в ответ не попадают.
3. Тест доказывает: при системной дате-воскресенье данные не теряются и API отвечает
   осмысленно; выборка по дате возвращает только записи этой даты.
