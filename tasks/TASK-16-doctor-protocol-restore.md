# TASK-16 — АРМ врача: сохранённый протокол виден в форме, а тест это доказывает

Две находки приёмки прогона `g_20260806-195014`:

- **P1: протокол не восстанавливается.** Форма берётся только из локального `visitForm`,
  иначе пустая ([doctor-page.tsx:85]); `complaints`, `diagnosis`, услуги и рекомендации из
  загруженного визита игнорируются. Данные на сервере есть — врач их не видит.
- **Нечестный гейт:** тест «переживает перезагрузку» проверяет содержимое собственного
  fetch-мока ([doctor-page.test.tsx:312]), а в DOM после перерендера смотрит только статус
  ([doctor-page.test.tsx:326]). Интерфейс может не восстановить ничего — тест зелёный.

- `src/pages/doctor/visit-form.tsx`

## Готовность

1. При выборе визита форма заполняется из данных визита: жалобы, диагноз, тип приёма,
   выполненные услуги, рекомендации. Локальные правки не теряются при переключении между
   визитами и возврате обратно.
2. Завершённый визит показывается в режиме чтения: повторно завершить его нельзя
   (сервер такой переход тоже отклоняет — TASK-15).
3. Тест проверяет ЗНАЧЕНИЯ В DOM после перерендера — жалобы, диагноз, услуги,
   рекомендации, — а не содержимое собственного мока; тест падает, если убрать заполнение
   формы из загруженных данных.
