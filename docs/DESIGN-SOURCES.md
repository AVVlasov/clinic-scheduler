# Источники дизайна: `_ds` vs документ

**Решение владельца (2026-08-10):** при расхождении визуальных токенов главный источник —
макеты, сборка `ai/05-дизайн/Clinic-scheduler UI макеты/_ds/`. Документ
`ai/05-дизайн/smclinic-Design-System.md` — справочник; при конфликте правится код
(и при необходимости документ), не макеты.

Ниже — известные расхождения и принятый источник для каждого.

| # | Тема | `smclinic-Design-System.md` | `_ds` | Принято |
|---|------|-----------------------------|-------|---------|
| 1 | Шрифт UI | Open Sans 400/700 | Golos Text 400/500/600/700 (+ Open Sans в стеке) | `_ds` |
| 2 | Радиусы | 0 / 4px / 40px (пилюля) | 0 / 4 / 6 / 8 / 12 / 999 (пилюля) | `_ds` |
| 3 | Веса | 400 и 700 | 400 / 500 / 600 / 700 | `_ds` |
| 4 | Тени | по сути нет (плоские поверхности) | elev-1..3, ring | `_ds` |
| 5 | Заливка занятого слота | пастель / tint по документу | `--slot-booked-fill: green-100`, bar green-500 | `_ds` |
| 6 | Текст на `#F07A35` | тёмный, не белый | `--text-on-orange: n-900` (всегда тёмный) | оба совпадают → `_ds` |
| 7 | Текст на зелёной заливке | белый &lt;18px запрещён; `-700` для текста | белый на ≥ green-600; иначе `-700` | `_ds` |
| 8 | Палитра 500 | `#0D9B6C`, `#F07A35`, `#DC5658` | те же 500 в комментариях `_ds` | совпадают |
| 9 | Нейтрали / surface | `#F5F7F6`, `#E0E6E3`, … | OKLCH n-* (`--surface-light` и др.) | `_ds` |
| 10 | Подключение шрифтов | описано, в рантайме не было | `tokens/fonts.css` + файлы в `assets/fonts` | `_ds` |

Токены в `src/__data__/tokens.ts` и тема Chakra сверяются тестом с CSS `_ds`
(`tokens.test.ts`): расхождение ломает прогон.
